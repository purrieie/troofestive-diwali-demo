# TrooFestive Diwali demo store

A demo D2C store ("Saanjh Botanicals", not a real brand) with TrooFestive's Diwali mode switched on, made by Troopod.

- `index.html`: home page
- `product.html`: product page
- `assets/`: the TrooFestive Diwali engine, the same files the Shopify app and the theme install use
- `img/`: the demo product images

Every feature is on:
- lights, side strands and kandils;
- diyas beside section titles and glowing buttons;
- the chakri between pages, the phuljhadi cursor and tap sparks;
- a firework on Add to cart and the shagun envelope.

Add `?troofestive=off` to any URL (or use the link in the top ribbon) to see the store without it.
